# 11 — Korean title options

## Recommended

### 일본은 대만을 포기했다… 그런데 누구에게 넘겼을까?

- Clear contradiction.
- Natural Korean phrasing.
- Matches the thumbnail question.
- Does not assert a disputed recipient.

## Alternatives

1. **일본은 왜 패전 후 대만을 지킬 수 없었을까?**  
   Direct match to the central question; slightly less distinctive.

2. **1951년 조약에는 대만을 받을 나라가 없었다**  
   Strong hook; should only be used if the thumbnail does not repeat the same wording.

3. **일본이 대만을 포기한 조약의 이상한 한 문장**  
   Fits the `기묘한 기록실` archival identity.

4. **한국전쟁이 대만의 운명을 바꾼 순간**  
   Strong Korean-market angle, but covers only the second half of the episode.

5. **일본 패전 뒤, 대만은 왜 곧바로 정리되지 않았나**  
   More analytical and less clickable.

## Pairing recommendation

- Title: `일본은 대만을 포기했다… 그런데 누구에게 넘겼을까?`
- Thumbnail: `누구에게 넘겼나?`
- Opening line: begin directly with the 1951 treaty, not the 1895 history.
