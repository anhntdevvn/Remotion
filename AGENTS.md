# Project instructions

Before researching, scripting, storyboarding, generating assets, building Remotion scenes, or rendering an episode, read and follow [MASTER_CHANNEL_BIBLE.md](./MASTER_CHANNEL_BIBLE.md).

At the start of a new conversation or when continuing an episode, also read [EPISODE_HANDOFF.md](./EPISODE_HANDOFF.md), then the current episode's README and QA. For episodes using animated character rigs, read [ANIMATION_DIRECTION_PLAYBOOK.md](./ANIMATION_DIRECTION_PLAYBOOK.md) before choosing actions, staging, scene grammar, or modifying the rig. These files preserve decisions and their reasons; do not rely on access to earlier chat history.

Treat reference videos as production blueprints only. Analyze their structure, pacing, scene functions, and production techniques, then create independently researched, original Korean scripts with parallel Vietnamese review scripts, storyboards, visuals, narration, and Remotion compositions. Follow the Master's reference mapping and narration–visual alignment rules.

The canonical channel and production rules are maintained in `MASTER_CHANNEL_BIBLE.md`. If another project document conflicts with it, follow the latest explicit user instruction and update the Bible when requested.

Improve rig episodes in this order: meaningful actions, reduced slide feel, varied scene grammar, narrative micro-hooks, character–object–environment interaction, then transition/camera/effect polish. Standing explanations and small amounts of looping remain valid when they serve the narration. Do not add arbitrary action or weapons for movement alone.

Default delivery after edits is working code, suitable checks, localhost Studio preview, and the exact render command. Do not automatically render MP4s, preview clips, or still frames; render only when explicitly requested. Preserve earlier episode versions and outputs when developing the separate V3 variant or any user-requested new variant.

After significant work or a new user decision, update the handoff with the actual state, verification evidence, and unresolved items. Add reusable directing lessons to the playbook; keep episode-specific counts, voice presets, and paths out of general channel rules. Verify the current files before treating older QA or handoff entries as current facts.
